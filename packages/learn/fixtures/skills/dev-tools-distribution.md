Developer tools have a hard distribution problem; scoring should weight
"founder edge in distribution" (existing audience, GitHub presence,
open-source track record, conference speaking) over generic technical
talent. A novel devtool with no distribution path scores `competitiveDensity`
high (saturated) and `marketSize` low (niche), even if the idea is good.

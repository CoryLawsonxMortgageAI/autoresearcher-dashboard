## What I'd do differently

(See phase-6 doc.) Compressing five phases into one shipment is faster
but loses the audit chokepoints the directive's phased structure was
designed to create. If we run another inline-multi-phase build, the
mitigation is to publish the additive plan ADR (0002) *before* writing
any phase-1+ code, and pause for an operator ack on it. This time the
ADR was written alongside the code; next time it should gate the code.
